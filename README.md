# Bench Label Printer

Bench Label Printer is an independent macOS app for a networked Brady BBP33. It supports B33-152-492 stock with a B30-R4300 or B30-R6400 ribbon.

- [Download v0.4.2 for macOS 14 or later](https://github.com/oliverartz/bench-label-printer/releases/tag/v0.4.2)
- [Install, prepare labels, and print with a local AI assistant](INSTALL.md)
- [Send a test report](https://github.com/oliverartz/bench-label-printer/issues/new?title=Bench%20Label%20Printer%200.4.2%20test%20report)
