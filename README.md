# Bench Label Printer

Bench Label Printer is an independent macOS app for a networked Brady BBP33. It supports B33-152-492 stock with a B30-R4300 or B30-R6400 ribbon.

[Download the v0.4.2 test release](https://github.com/oliverartz/bench-label-printer/releases/tag/v0.4.2).

The release includes Apple silicon and Intel installers for macOS 14 or later, setup instructions, and a one-row test.
